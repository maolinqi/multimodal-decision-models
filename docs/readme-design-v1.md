# GitHub 首页设计说明 · 第一版

主标题：System One。主题：全模态 System One 决策模型。主文案：从多模态观测到结构化决策与动作建议。

首页按“品牌与开源入口 → 项目定位 → 我们的工作 → 决策通路 → 当前能力 → 模型基座 → 快速开始 → 验证 → 路线图 → 开源范围”组织。首屏说明我们实现的决策通路，技术参数和验证边界位于相应章节。

参考页面：

- [OpenVLA](https://github.com/openvla/openvla)：参考清晰的任务定位、导航与 Getting Started 组织方式。
- [LeRobot](https://github.com/huggingface/lerobot)：参考开源模型、工具、贡献和易用性的呈现方式。
- [MiniCPM-V](https://github.com/OpenBMB/MiniCPM-V)：参考能力介绍、模型列表、使用指南与评测记录的章节安排。

内容与代码贡献独立撰写，不引用他人的性能、论文、演示或模型训练成果作为本项目证据。

当前已验证的是多模态决策接口；全模态是拓展目标。音频等未接入部分明确标为路线图，不宣称发布了重新训练的全模态权重或实时闭环能力。

第一版完整文稿位于仓库根目录 `README.system-one-v1.md`，现有 `README.md` 暂时保留，便于比较两版介绍。
