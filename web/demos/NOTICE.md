# Demo material

The four `civil-*` PNGs are unmodified question images from Huatu's public past-exam collection: https://gs.huatu.com/2024/0808/1771187.html . Individual JSON files record image URLs, exam item identities and SHA-256 hashes. They retain their original owners' rights and are not relicensed under the repository's Apache-2.0 code license. The collection identifies the 2022/2023 items as recollections rather than official examination-board releases.

Red-ball, fictional booking-page and greenhouse illustrations were created for this repository. Input fixtures contain no reference answers; submitted payloads are assembled from questions, state text, options and original image bytes only.
